[Current Version]
1. Sample data are selected by hourly
2. Developer manually label the first hour data
2. Initialize model with first hour of data
3. Select the next hour of data
4. Classify the SMS with the Initialized model
5. Separate result by confidence score
    -> if the model return confidence score greater than 0.9 then fit to the model else skip those SMS
6. Repeat step 3 - 5

In step 11, the data to save includes:
    a. row_id (auto increment id for table)
    b. id (id of the message)
    c. datetime (the time the message sent)
    d. spam_label (result of model)
    e. confidence_score (how confidence the model is)
    f. label_status
        -> Currently, there are 3 kinds of status: [1, -1, 0] 
        -> '1' indicates it requires human manully labelling 
        -> '-1' indicates it has been labeled by model with high confidence score
        -> '0' indicates it has moderate confidence score, still have a chance to be selected as a sample data
    g. model (the model name)
