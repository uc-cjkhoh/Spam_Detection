[Current Pipeline]
1. Setup required components (database, model, etc)
2. Check if has existing model
    -> if no
        -> Stratified sampling by time of day of specific day
        -> Save then in local as .xlsx (Excel)
        -> Terminate module
        -> Developer manually label the first batch of data
        -> Re-run the module, move to Step 1
    -> if yes:
        -> Initialize or Train Model
3. Select another batch of data with stratified sampling
4. Normalize data
5. Convert data to vectors
6. Perform dimension reduction
7. Classify them with the model
8. Label high confidence sms as 'pseudo', confidenec score >= <threshold>
9. Label manually <n> uncertain sms, where their confidence score should be closest to |p - 0.5| as 'human'
10. Label the rest as '' 
11. Save or update metadata of the result and data 
12. Repeat step 3 - 11
